# Einheiten → Quests

*Jede Einheit des Kurses hat ein Code-Wort. Der Code am Ende der Stunde öffnet genau diese Quest. Wer gefehlt hat,
bekommt die 3-Minuten-Kurzfassung.*

**Art:** **T** = trägt die Einheit (das Thema ist der Kern der Spannung) · **B** = berührt sie (Werkzeug als Spielregel,
Bauplan oder Moment) · **S** = vor allem Geschichte und Spaß.
**Gespräch:** Leine = Leine halten · Oberfläche = Unter der Oberfläche · Echolot · Gegenwind · Knoten = Der Knoten.
**Bestehend** heißt: in der Hafen-Demo oder als Minispiel schon gebaut.
