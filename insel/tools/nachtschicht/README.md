# Nachtschicht (automatischer Weiterbau)

Eine Routine („LUMO Nachtschicht“) prüft alle 2 Stunden den Bau und setzt ihn fort:
1. Vertical Slice Module 0–3 (läuft)
2. Staffel 1 komplett: Module 4–9, Lehrerheft, Integration, Prüfung, Politur
3. Vorbereitung CDSE-Hub: ELDiB → Insel-Fokus, Hub-Karte, Fokus-Code/QR

Bricht ein Lauf wegen des Sitzungslimits ab, wird er nach dem Reset fortgesetzt.
Die Routine lässt sich auf claude.ai unter den Routinen pausieren oder löschen.
Die Dateien hier sind eine Sicherung der Steuer-Skripte (Original im Scratchpad der Session).
